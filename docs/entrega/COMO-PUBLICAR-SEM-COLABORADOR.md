# Entregar os arquivos ao responsável do repositório

O usuário informou que ainda não é colaborador. Não é necessário compartilhar senha ou token. O pacote ZIP preparado nesta máquina contém os arquivos da versão revisada, sem .git, node_modules, .next, data, tmp ou .env.

1. Envie o ZIP ao proprietário ou a um colaborador autorizado. O agente não enviou mensagens nem publicou em seu nome.
2. Essa pessoa deve conferir o pacote e comparar com a versão atual do repositório antes de copiar, para preservar trabalho novo de outros integrantes.
3. Copie os arquivos para um checkout atualizado. Leia `docs/entrega/revisao-final.md`, especialmente a diferença entre geração local e serviços externos.
4. Execute as verificações de `AGENTS.md`; revise `git diff` e `git status`. Confirme com a equipe a spec revisada.
5. Crie commits com descrições do que está sendo publicado, sem inventar uma sequência retroativa; faça push com a própria conta autorizada. Registre o hash final.
6. Outro integrante deve seguir `VALIDACAO-OUTRO-INTEGRANTE.md` a partir de clone novo.
